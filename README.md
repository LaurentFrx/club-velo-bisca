# Club Vélo Bisca

Application de gestion d'un club de cyclotourisme (adhérents, comptabilité, circuits GPS, actualités, assemblée générale).
Une seule page HTML hors ligne, qui lit et écrit un fichier Excel unique.

Le bouton « Découvrir avec un club imaginaire » permet de la découvrir sans aucune donnée réelle.

## Installer l'application

Adresse : https://laurentfrx.github.io/club-velo-bisca/

- **PC (Chrome ou Edge)** : ouvrez l'adresse, puis cliquez sur l'icône « Installer » à droite de la barre d'adresse. L'application a alors sa propre fenêtre, un raccourci sur le bureau et dans le menu Démarrer, et fonctionne aussi sans internet. Un fichier Excel du club peut ensuite s'ouvrir avec elle (clic droit sur le fichier > Ouvrir avec).
- **iPhone / iPad (Safari)** : bouton Partager, puis « Sur l'écran d'accueil ».
- **Android (Chrome)** : menu ⋮, puis « Installer l'application ».

Les données ne sont jamais envoyées sur internet : chacun ouvre le fichier Excel du club depuis son appareil.
